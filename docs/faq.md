# 常见问题

## 这是完整客户端和服务端源码吗？

公开仓库以 C++/Tars 服务端为主。虽然存在 Unity 包和项目设置目录，但根目录未看到完整 `Assets/`，因此不能据此确认完整客户端可构建。

## 如何下载？

在 [仓库首页](https://github.com/masterai-top/Texas-Holdem-Poker-Game-Server-Club-Source-Code) 点击 **Code → Download ZIP**。

## 是否包含扑克 AI？

当前公开目录未显示明确 AI 模块，因此不建议使用 `poker-ai` Topic 或宣称已包含 AI。

## 能否直接商业运营？

不能仅凭公开仓库判断。必须确认许可证、完整组件、构建状态、安全审计和所在地法律要求。
