## 🚀 Project Overview


This project provides the complete source code for a Texas Hold'em poker platform.


It includes real-time multiplayer games, classic Texas Hold'em, Short Deck, single-table tournaments, multi-table tournaments, private games, MTT, and SNG tournament systems.


## ✨ Core Features


| Module | Description |
| :--- | :--- |
| 🎮 **Game Modes** | Classic Texas Hold'em, AOF, 6+ Short Deck, SNG, MTT, and clubs |
| 👥 **Social System** | Private games, clubs, competitor alliances, friends, and mail |
| 🎁 **Live Operations** | Daily login, missions, jackpot, scratch cards, prize wheel, friend invitations, and rewarded ads |
| 🏪 **Store System** | Item purchases, treasure chests, leaderboards, and vault |
| 📱 **Multi-Platform Support** | iOS app, Android app, H5, and Web |

- **Server:** C++ (stable and efficient)
- **Client:** Unity / Cocos (iOS and Android support)
- **Database:** MySQL + Redis
- **Communication:** Proprietary encrypted protocol
